# NeuronGuard: Pure Python Static Expression & Gesture Cloner

A 100% self-contained neuromorphic network that learns custom facial expressions and kinetic gestures on the fly by tracking localized motion variance directly.

---

## How to Run

```bash
# Run the Expression Cloner
mise run expression_cloner
```

---

## Controls & Instructions
* **Instructions**: 
  1. Press a number **[0, 1, 2, 3]** to select a target Expression/Gesture Slot.
  2. Perform an action (e.g., Smile, Shock, Wave).
  3. **HOLD DOWN the [SPACEBAR]** to instantly wire the active network path to the current slot.
  4. Release the spacebar and watch it instantly detect and recognize your action!
* **Controls**: 
  - Switch Slots: Press **[0, 1, 2, or 3]**
  - Train: Hold **[SPACEBAR]**
  - Exit: Press **[Esc]**
