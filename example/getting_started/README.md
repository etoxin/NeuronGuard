# NeuronGuard: Getting Started Guide

This example introduces the core concepts of the `neuronguard` Python library.

---

## What You Will Learn
1. **Initializing a Cortex**: Setting up a `NeuronGuardField` with sensory and motor neurons.
2. **Configuring Connections**: Manually mapping sensory tokens to motor neurons.
3. **Real-Time Inference (Run Mode)**: Processing active stimuli streams with dropped GIL.
4. **Supervised Learning (Trainer Mode)**: Training connections dynamically on the fly.
5. **Instant Serialization**: Saving and loading model weights in `< 1ms`.

---

## How to Run

```bash
# Run the Getting Started Guide
mise run getting_started
```
